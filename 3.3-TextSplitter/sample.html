AI Engineering Guide

This guide covers the core building blocks of modern AI applications.

Large Language Models

Large language models are neural networks trained on huge amounts of text to predict the next token.

Transformers

The transformer architecture uses self-attention to let every token look at every other token in the input.

Context Window

The context window is the maximum amount of text a model can read at once. Long documents must be split into chunks to fit.

Retrieval-Augmented Generation

RAG gives a model access to external knowledge by retrieving relevant chunks and adding them to the prompt.

Document Loaders

Loaders read data from files, web pages, or APIs and turn it into Document objects with content and metadata.

Text Splitters

Splitters break documents into smaller chunks. Some split by characters, while others split by structure such as HTML headers.

Vector Stores

Vector stores save embeddings of each chunk so the most similar chunks can be found quickly for a given question.

Deployment

Production AI systems need monitoring, cost control, caching, and protection against prompt injection.

APIs

A common pattern is to wrap the RAG pipeline in a FastAPI backend so other applications can call it.
